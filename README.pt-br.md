# Curitibars

[English](README.md) · Português

Site estático (HTML e CSS) com um pequeno guia de bares de Curitiba: menu lateral fixo,
uma seção por bar com foto, endereço e descrição, e uma página separada com formulário
de contato.

Projeto em dupla, desenvolvido em conjunto com Emelize Bonfim Mlot
([@liz-whs](https://github.com/liz-whs)), dona do repositório original. Este é um fork
mantido na conta da Giovanna como referência de portfólio; o trabalho nas páginas e nos
estilos foi feito em conjunto.

**Site:** https://ribasgiovanna.github.io/Curitibars/

![Curitibars](docs/home.png)

## Estrutura

```
.
├── index.html       # listagem dos bares, com navegação lateral
├── formulario.html  # formulário de contato
├── style.css        # estilos da listagem
├── styleform.css    # estilos do formulário
└── img/             # fotos dos bares
```

## Como abrir

Abra o `index.html` no navegador. Não há etapa de build nem dependências.

## Tecnologias

- HTML
- CSS
- Remix Icon (fonte de ícones, via CDN)
